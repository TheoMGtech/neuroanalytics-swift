# Diretório de Dados - NeuroAnalytics

Este diretório contém os dados utilizados pelo projeto:

- `raw/`: Dados originais e não modificados (contém `Dados para o Grillo.xlsx` e `Transacoes Lojas.xlsx`). *Estes arquivos são ignorados pelo git*.
- `processed/`: Dados após a etapa de limpeza e tratamento (salvos temporariamente em memória na aplicação).
- `samples/`: Arquivos de exemplo pequenos para fins de demonstração ou testes rápidos (como `exemplo_avaliacoes.csv`).
