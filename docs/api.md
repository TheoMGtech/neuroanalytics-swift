# Documentação de endpoints da API

Consulte os docs do Swagger rodando o backend na rota `/api/docs`.
- `POST /api/upload`: Processamento de planilhas.
- `GET /api/history`: Listagem de análises persistidas.
- `GET /api/history/{id}`: Detalhes de uma análise.
- `DELETE /api/history/{id}`: Exclusão de registro.
- `GET /api/health`: Saúde da aplicação.
